# Short walkthrough

[Watch the 42-second MP4](meeting-actions-demo.mp4) · [Transcript](transcript.txt)

The video uses edited still captures from the successful live gateway run and the subsequent human review. It shows fictional notes being turned into tasks, missing ownership/deadlines, manual confirmation and the resulting exports. Request waits are omitted. The guest-task owner and date are explicit human demo choices.

Narration uses the macOS Samantha speech voice; captions explain the workflow with sound off. The file is approximately 1 MB, H.264/AAC, 1440 × 900. Its streams were fully decoded and sampled frames inspected before publication. It is a workflow tour, not a continuous recording or performance benchmark.
